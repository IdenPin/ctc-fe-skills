通用前端页面布局模板与插槽契约规范 (v5.1 定稿版) 已合并 Codex 架构复审意见 · 零契约漂移 · 宿主高度链防御
L01 标准工作台检索布局（Standard Filter-Viewport-Page）
适用场景：台账检索、时序数据监测(表/图双态)、日志审计、标准增删改查
空间拓扑：纵向单列流 (筛选区 ➔ 操作工具栏 ➔ 自适应主视口 ➔ 分页/底栏)
高度契约：宿主提供可用高度 ➔ 布局 height: 100% 填满；收缩链保持 min-height: 0; min-width: 0;
滚动归属：外层 overflow: hidden; 严禁外层双滚动；#main-viewport 内部或由子组件(如 el-table)自负责滚动
公开插槽：#filter-bar, #toolbar, #main-viewport (必需), #footer-bar (可选)
#filter-bar
多维表单查询、时间范围、级联下拉、查询/重置按钮组 (支持展开/折叠)
[可选插槽 · 缺省不占位] [无滚动 · 紧凑排布]
#toolbar
新增、批量导出/下发、列设置、视图形态切换 (表格态 ⇄ 趋势图态)
[可选插槽 · 缺省不占位] [无滚动 · 工具条]
#main-viewport
占满剩余可用视口高度 (flex: 1; min-height: 0; min-width: 0;)
[必需插槽 · 滚动归属：内部表格/列表子组件自负责滚动] [可接入：高密度表格 / 虚拟列表 / 时序对数趋势图 / 复杂表头矩阵]
#footer-bar
状态图例说明 (正常/超标/异常)、总条数统计、分页控制器 (PageSize / Jumper)
[可选插槽 · 缺省不占位] [不被内容挤压 · 贴底可见]
L02 侧栏联动主从布局（Sidebar Tree/Nav Split）
适用场景：组织树/排口树查表、设备视频监控通道、流媒体巡检、分类目录台账
空间拓扑：横向双栏：左固定宽侧栏 (240~280px) + 右自适应工作区 (1fr)；可与 L03 共享双栏底层实现
高度契约：容器 height: 100%；左右两栏均为 height: 100%
滚动归属：双轨独立滚动：左侧侧栏容器独立纵向滚动 (overflow-y: auto)；右侧工作区滚动权归属其装配内容
公开插槽：#sidebar-nav (必需), #content-header (可选), #content-body (必需), #content-footer (可选)
#sidebar-nav
固定宽 240~280px | 承载树形导航/分类目录
[必需插槽 · 滚动归属：布局侧栏容器独立滚动 overflow-y: auto] [可接入：行政区划树 / 排口设备树 / 目录索引]
#content-header
当前节点上下文摘要、业务维度 Tab (如视频查看/日志/联网趋势)、轻量筛选
[可选插槽 · 缺省不占位]
#content-body
占满剩余视口 (min-height: 0;) | 随左侧选中节点动态联动
[必需插槽 · 滚动归属：由装配内容负责滚动] [可接入：音视频流媒体视口 / 关联数据表格 / 因子对比分析图]
#content-footer
底部分页器、诊断状态说明、操作控制栏
[可选插槽 · 缺省不占位]

滚动归属：左侧清单容器独立滚动；右侧正文区独立滚动；右侧操作栏常驻吸底可见
公开插槽：#master-filter (可选), #master-list (必需), #detail-head (可选), #detail-body (必需), #detail-actions (可选)

#detail-head
选中对象标题、状态徽章、操作按钮组
[可选插槽]
#detail-body
从属核心处理工作区 (现场证据链、整改填报表单、联动城市管理表格)

#detail-actions

L04 全景空间底图 + HUD 浮层布局（GIS-HUD-Overlay）
适用场景：生态环境一张图、流域水质大盘、污染源监管大屏、3D 数字孪生
空间拓扑：底层全景画布 (100% 视口) + 上层 HUD 悬浮面板栅格 (顶/左/右/底)
高度契约：填充宿主或全屏外壳可用空间；地图画布保证最小可用尺寸 (默认 min 320px)
交互与穿透：HUD 浮层外框 pointer-events: none 穿透底图；内部卡片面板恢复 pointer-events: auto
公开插槽：#canvas-bg (必需), #hud-top, #hud-left, #hud-right, #hud-bottom-left, #hud-bottom-right (均可选)
#canvas-bg
底层全景画布视口 (响应鼠标原生拖拽、缩放、点位悬浮高亮、空间框选)
[必需插槽 · 滚动归属：无滚动 · 组件响应 Resize] [接入：天地图 / 高德 / Mapbox / 3D 孪生]
#hud-top 顶部统揽指标栏 (联网企业数、今日报警数、优良水体占比、区域切换器)
#hud-left 左侧态势分析 (工作进展卡、分类图层树、达标率排行)
#hud-right 右侧实时事件 (实时异常线索流、任务办理进度、预警处置卡)
#hud-bottom-left [图例插槽] #hud-bottom-right [空间工具：测距/框选/图层开关]
L05 复合双栏核查工作台（Dual-Pane Review Workbench）
适用场景：公文派发+审批流程比对、涉案证据核验、深度两段式案卷核实
定位与解耦：**纯双栏内容布局**；浮层外壳直接使用 CtcDialog / CtcDrawer（原生 48px Header 与 Footer），L05 专注双栏核查
空间形态：装配在开启 contentFill 的 CtcDialog (居中) 或 CtcDrawer (宽幅抽屉 68%~75%) 中
滚动与禁滚：宿主外壳 overflow:hidden 抑制嵌套滚动；左栏与右栏各自持有独立纵向滚动条
公开插槽：#pane-left (必需), #pane-right (必需)
[外壳原生 Header: CtcDialog / CtcDrawer 管控 48px 标题与关闭/全屏控件] [外壳原生]
#pane-left [证据/公文/静态审阅]

[必需插槽 · 滚动归属：左栏独立纵向滚动]
#pane-right [流转/审批/动态填报]
四级审批流转步骤条 / 现场勘验结论录入 / 责任人签名 / 附件上传
[必需插槽 · 滚动归属：右栏独立纵向滚动]
[外壳原生 Footer: 确定 / 取消 / 审批流转操作区] [外壳原生]
L06 响应式网格看板布局（Dashboard Grid Analytics）
适用场景：整改情况统计、运维质量分析、设备注册总览、领导驾驶舱
空间拓扑：全局维度筛选 ➔ 指标卡自适应行 (CSS Grid repeat) ➔ 通用自适应图表网格
解耦说明：已移除特型化图表命名，采用开放栅格插槽契约，防止向复杂拖拽系统退化
滚动与响应：视口整体或网格区自适应纵向滚动；各图表卡片必须监听 ResizeObserver 触发尺寸更新
公开插槽：#dashboard-filter (可选), #metric-cards (可选), #dashboard-grid (必需)
#dashboard-filter
统计维度筛选 (时间范围、区划下钻、线索类别、按月/按日单选)
[可选插槽]
#metric-cards
指标卡容器 (采用 repeat(auto-fit, minmax(180px, 1fr))，自动均分 3~5 个大数字卡)
[可选插槽 · 容器自适应排列]
#dashboard-grid
开放响应式图表网格容器 (支持 2:1、2x2、3列 等通用布局，装配柱状图/折线图/环形图/排行榜)
[必需插槽 · 滚动归属：视口或网格纵向滚动] [响应契约：图表组件内部必须监听 ResizeObserver]
L07 锚点分段长卷档案布局（Anchor-Section Profile & Form）
适用场景：排污许可申报与核发全流程、排污单位一企一档全量画像、站房建设标准化台账
空间拓扑：顶部摘要 + (侧边浮动锚点轨 160px + 纵向多分段长卷 1fr) + 吸底操作栏
滚动与锚点：**正文容器为唯一滚动根节点**；侧边锚点菜单悬浮跟随并高亮联动；操作栏位于正文滚动区外，自然可见
命名对齐：长卷内容插槽严格命名为 #sections-stream（消除之前的数字槽位歧义）
公开插槽：#profile-header (可选), #anchor-nav (必需), #sections-stream (必需), #sticky-actions (可选)
#profile-header
实体核心概要 (企业名称、统一社会信用代码、排污许可证号、环保信用等级徽标)
[可选插槽]
#anchor-nav
锚点导航索引轨 (跟随右侧唯一的滚动根节点实时计算偏移与高亮)
[必需插槽 · 滚动根节点必须为统一的父级容器]
#sections-stream
多分段内容流容器 (按业务填入 Section 1 基本概况、Section 2 治理设施、Section 3 限值等)
[必需插槽 · 统一长卷滚动 · 不在子区块内嵌套局部滚动条]
#sticky-actions
常驻操作动作条 (存为草稿、自动合规性比对校验、提交主管部门审核)
[行为契约：位于滚动区外，始终贴底可见]

滚动规则：单视口受控切换；当前步骤工作区根据内容自负责纵向滚动
