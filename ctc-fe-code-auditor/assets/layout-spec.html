CtcReport 原生插槽契约
#search-bar可选条件搜索筛选栏（支持 search-bar-left/right）。
#tool-bar可选操作工具栏（支持 tool-bar-left/right 左右分流）。
#container-top可选内容容器顶部；承载统计指标概览、KPI 卡片或分类页签。
#table-bar可选表格顶栏；承载 table-title 标题与 table-info 状态信息。
#default可选默认自定义插槽；位于表格前置区域，插入自定义内容。
#append-table可选表格后置追加区域；承载批量勾选下发或操作确认底栏。
#pagination可选卡片内分页区域；按配置启用并保持在布局底部。
布局硬性规则
  • 外围工作区采用统一底色变量，白卡四边保留相同外间距。
  • 父级高度链明确，表格通过 min-height: 0 占满剩余视口空间。
  • 100% 对应 @ctc-front/components-ui-next 中的 CtcReport 真实结构，核心表格由内置 CtcTable 承载（通过 :columns 属性驱动，无 columns 容器插槽）。
纯布局调用示例
使用 T01_STANDARD_TABLE_PAGE，mode: layout，启用 search-bar、tool-bar、container-top、pagination，输出区域骨架（或直接引用参考实现 TablePageLayout.vue）。业务页面输入见配置示例。

插槽契约 (Slot Schema)
#sidebar-tree必需左侧层级导航；过滤、折叠和联动按配置启用。
#toolbar必需当前上下文下的查询工具区域。

  • 树选择联动按配置启用，不强制所有点击防抖。

插槽契约 (Slot Schema)
#master-list必需左侧主清单容器（支持独立纵向滚动与当前项高亮）。

  • 切换左侧主项时，若右侧存在未保存数据须触发脏检查。
